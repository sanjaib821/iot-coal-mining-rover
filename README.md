
# IoT Based Underground Coal Mining Rover

## Project Overview
The IoT-Based Underground Coal Mining Rover is designed for toxic gas detection, environmental monitoring and real-time surveillance in underground coal mines.

The system uses an ESP32 microcontroller to monitor hazardous gases and environmental conditions, helping improve mine worker safety through remote monitoring.

## Objectives
- Detect toxic and combustible gases.
- Monitor temperature and humidity.
- Measure light intensity and moisture.
- Provide real-time video surveillance.
- Control the rover remotely using Blynk.
- Upload sensor data to ThingSpeak Cloud.

## Hardware Components
- ESP32 Microcontroller
- ESP32-CAM
- MQ-9 Gas Sensor
- MQ-135 Gas Sensor
- DHT11 Temperature and Humidity Sensor
- LDR Sensor
- Moisture Sensor
- L293D Motor Driver
- DC Geared Motors
- Servo Motor
- 16x2 LCD Display
- Buzzer
- Power Supply

## Software and Technologies
- Arduino IDE
- Embedded C/C++
- Blynk IoT
- ThingSpeak Cloud
- Wi-Fi Communication

## Working Principle
The ESP32 collects sensor readings and displays them on the LCD. The data is uploaded to ThingSpeak every 20 seconds. The rover can be controlled remotely through the Blynk mobile application. The ESP32-CAM provides live video surveillance using a servo motor.

## Applications
- Underground coal mine monitoring
- Toxic gas detection
- Environmental monitoring
- Industrial safety
- Remote surveillance
